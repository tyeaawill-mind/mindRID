# mindRID — final reliable engine deployment build

This is the clean replacement build for the current mindRID site.

Includes:
- Whisper and reply creation
- image, video and audio attachments
- anonymous / real identity mode
- public / selected / private visibility
- selected-recipient management
- edit and delete for own content
- like, save, direct-share and report controls
- persistent Saved section
- loading, progress, completion and error feedback
- direct Whisper links
- Supabase authentication, database and private media storage

**Welcome email is intentionally removed from this build.** There is no welcome-email Edge Function and no Gmail integration.

See `DEPLOY-FINAL.md` for the deployment sequence.
